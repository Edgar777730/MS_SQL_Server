🔹 Введение
Microsoft SQL Server — это корпоративная реляционная система управления базами данных (СУБД), построенная по клиент-серверной архитектуре. Это означает, что клиент (пользователь или приложение) отправляет запросы на сервер, а сервер их обрабатывает и возвращает результат. Такая архитектура обеспечивает высокую производительность, безопасность и централизованное управление данными.

SQL Server широко используется в крупных компаниях для хранения и обработки больших объёмов информации, построения отчётов, аналитики и автоматизации бизнес-процессов.

🔹 Среда разработки
После нажатия кнопки «Соединить» открывается окно среды разработки, которое состоит из нескольких основных элементов:

1. Оконное меню
Содержит полный набор команд для управления сервером и выполнения различных операций. Через него можно создавать, изменять и удалять объекты, настраивать параметры сервера и выполнять многие другие действия.

2. Панель инструментов
Содержит кнопки для наиболее часто производимых операций. Внешний вид данной панели зависит от выполняемой операции, то есть она является контекстно-зависимой и подстраивается под текущие задачи пользователя.

3. Панель «Object Explorer» (Обозреватель объектов)
Это панель с древовидной структурой, отображающая все объекты сервера, а также позволяющая производить различные операции как с самим сервером, так и с базами данных. Обозреватель объектов является основным инструментом для разработки БД, так как через него удобно просматривать структуру, создавать новые объекты и управлять существующими.

4. Рабочая область
В рабочей области производятся все действия с БД, а также отображается её содержимое. Здесь можно писать запросы, просматривать результаты их выполнения и работать с таблицами.

🔹 Создание базы данных
База данных состоит из двух файлов:

📁 Файл данных — в нём хранится вся информация БД;

📝 Журнал транзакций — в него записывается информация до и после выполнения каждой транзакции.

Для создания БД в графическом интерфейсе нужно нажать на узел «Базы данных» (Databases) и выбрать создание новой базы.

⚠️ Примечание: при установке SQL Server 2025 и попытке создать БД через Management Studio могут возникать технические проблемы с подключением. В таком случае используется команда:

sql
CREATE DATABASE привет
🔹 Типы данных
SQL Server поддерживает множество типов данных, которые можно разделить на несколько категорий.

🔸 Битовые типы
Содержат последовательности нулей и единиц:

Binary(n) и Varbinary(n) — где n — длина.

🔸 Целочисленные типы
Для хранения целых чисел:

Тип	Диапазон
Tinyint	от 0 до 255
Smallint	от –32 768 до 32 767
Int	от –2 147 483 648 до 2 147 483 647
Bigint	от –9 223 372 036 854 775 808 до 9 223 372 036 854 775 807 (занимает 8 байт)
🔸 Типы для дробных чисел
Real — семь знаков после запятой

Float(m) — может хранить числа из m знаков после запятой, максимальное m = 38

Decimal(m, n) — дробные числа с m знаков до запятой и n после; хранит числа с фиксированной точностью

🔸 Специальные типы
Bit — логический тип данных (0 или 1), замена Boolean

Text — для хранения больших объёмов текста (до 2 Гб)

Image — для хранения до 2 Гб рисунков

RowGUID — уникальный идентификатор строки таблицы

SQL_Variant — аналог типа Variant

🔸 Типы даты и времени
Datetime — от 01.01.1753 до 31.12.9999

SmallDatetime — от 01.01.1900 до 06.06.2079

🔸 Денежные типы
Для хранения финансовой информации:

Money — ±10¹⁵ и 4 знака после запятой

Smallmoney — ±20 000.0000

🔸 Символьные типы
Char(n) — строка фиксированной длины n (дописывается пробелами, максимум 2000 байт)

Varchar(n) — строка переменной длины (хранятся только значащие символы, максимум 4000 байт, не Unicode)

Nvarchar(n) — строка переменной длины в кодировке Unicode (максимум 4000 байт)

🔹 Краткая сводка по числовым типам
Тип	Диапазон	Размер
BIT	0 или 1	1 байт
TINYINT	0 – 255	1 байт
SMALLINT	–32 768 – 32 767	2 байта
INT	–2 147 483 648 – 2 147 483 647	4 байта
BIGINT	–9 223 372 036 854 775 808 – 9 223 372 036 854 775 807	8 байт
DECIMAL	числа с фиксированной точностью	от 5 до 17 байт
🔹 Заключение
Таким образом, Microsoft SQL Server представляет собой мощную платформу для работы с базами данных, предоставляющую широкий набор инструментов для разработки, администрирования и работы с данными. Понимание архитектуры, среды разработки и типов данных является основой для дальнейшего изучения T-SQL и построения эффективных баз данных.
