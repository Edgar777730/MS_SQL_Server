# Триггер AFTER INSERT на STUDENT

## Что требовалось
Создать триггер на таблице STUDENT, который после вставки нового студента выводит сообщение с его именем.

## Что сделано

USE College;
GO

CREATE TRIGGER trg_AfterStudentInsert
ON STUDENT
AFTER INSERT
AS
BEGIN
    SET NOCOUNT ON;
    DECLARE @NewStudentName NVARCHAR(100);
    SELECT @NewStudentName = NAME FROM inserted;
    PRINT 'СИСТЕМНОЕ СООБЩЕНИЕ: В базу успешно зачислен новый студент — '
        + ISNULL(@NewStudentName, 'Неизвестно');
END;
GO

## Проверка

INSERT INTO STUDENT (IDGROUP, NAME, BDAY)
VALUES (1, 'Иванов Иван', '2005-01-01');

## Результат

Messages:
СИСТЕМНОЕ СООБЩЕНИЕ: В базу успешно зачислен новый студент — Иванов Иван

Results:
IDSTUDENT | IDGROUP | NAME | BDAY
18 | 1 | Иванов Иван | 2005-01-01

## Анализ
Триггер срабатывает автоматически после вставки. Таблица inserted содержит вставленные строки. ISNULL защищает от NULL. SET NOCOUNT ON убирает служебное сообщение.

## Вывод
Триггер корректно выводит сообщение после вставки студента. AFTER INSERT — стандартный тип для логирования и уведомлений.

## Стек
Microsoft SQL Server 2017, SSMS 22, база college.
