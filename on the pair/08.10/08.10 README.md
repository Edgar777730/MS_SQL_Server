## Слайд 24. Восстановление БД — параметры

| Параметр | Значение |
|---|---|
| WITH REPLACE | ☐ выкл |
| WITH KEEP_REPLICATION | ☐ выкл |
| WITH RESTRICTED_USER | ☐ выкл |
| Состояние восстановления | **RESTORE WITH RECOVERY** |
| Закрыть соединения | ☐ выкл |

**Разбор:**

| Параметр | Что делает |
|---|---|
| WITH REPLACE | Перезапись существующей БД |
| RESTRICTED_USER | Только админы подключаются |
| WITH RECOVERY | БД сразу доступна |
| WITH NORECOVERY | Для цепочки бэкапов |
| Закрыть соединения | Разрыв сессий перед восстановлением |

**Вывод:** `RECOVERY` — простое восстановление. `NORECOVERY` — для доката. `WITH REPLACE` — если БД существует.

5. Закрытие соединений — обязательно перед восстановлением.
