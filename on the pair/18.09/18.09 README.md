## Задача 1. Средний балл студента

### Что требовалось
Создать функцию GetStudentAvgGrade(student_id INT), которая возвращает средний балл студента по всем дисциплинам. Если оценок нет — возвращает 0.

### Что сделано
Создана функция, которая считает AVG(NOTE) по студенту. Если оценок нет, AVG вернёт NULL — заменяем на 0 через ISNULL.

CREATE OR ALTER FUNCTION dbo.GetStudentAvgGrade (@student_id INT)
RETURNS DECIMAL(4,2)
AS
BEGIN
    DECLARE @avg DECIMAL(4,2);
    SELECT @avg = AVG(CAST(NOTE AS DECIMAL(4,2)))
    FROM PROGRESS WHERE IDSTUDENT = @student_id;
    RETURN ISNULL(@avg, 0);
END;

### Результат

IDSTUDENT | NAME | Средний балл
1 | Алексеев Алексей Алексеевич | 9.50
2 | Борисова Борислава Ивановна | 6.50
8 | Зайцева Зоя Михайловна | 0.00
14 | Орлова Ольга Витальевна | 10.00

### Анализ
CAST нужен, чтобы AVG по INT вернул дробное число. ISNULL(@avg, 0) — если оценок нет, вернётся 0.

### Вывод
Функция корректно возвращает средний балл или 0. Студент 8 без оценок получил 0.00.

## Задача 6. Стипендия студента

### Что требовалось
Создать функцию GetScholarship(student_id), возвращающую 0 при среднем < 4, 2000 при 4 ≤ avg < 4.5, 3000 при avg ≥ 4.5.

### Что сделано
Функция считает средний балл и по нему определяет размер стипендии через IF/ELSE IF/ELSE.

CREATE OR ALTER FUNCTION dbo.GetScholarship (@student_id INT)
RETURNS INT
AS
BEGIN
    DECLARE @avg DECIMAL(4,2);
    SELECT @avg = AVG(CAST(NOTE AS DECIMAL(4,2)))
    FROM PROGRESS WHERE IDSTUDENT = @student_id;
    SET @avg = ISNULL(@avg, 0);

    IF @avg < 4      RETURN 0;
    IF @avg < 4.5    RETURN 2000;
    RETURN 3000;
END;

### Результат
Для наших студентов — 3000, 2000 или 0 (без оценок).

### Анализ
Функция переиспользует логику среднего балла. Порог разбит на 3 диапазона.

### Вывод
Размер стипендии определяется средним баллом по правилам задачи.

## Задача 8. Удаление студента с оценками

### Что требовалось
Создать процедуру DeleteStudent(student_id), которая удаляет студента и все его оценки в транзакции.

### Что сделано
Процедура открывает транзакцию, удаляет сначала оценки из PROGRESS, затем студента из STUDENT. При ошибке — ROLLBACK.

BEGIN TRY
    BEGIN TRANSACTION;
    DELETE FROM PROGRESS WHERE IDSTUDENT = @student_id;
    DELETE FROM STUDENT  WHERE IDSTUDENT = @student_id;
    COMMIT TRANSACTION;
END TRY
BEGIN CATCH
    IF @@TRANCOUNT > 0 ROLLBACK;
    PRINT 'Ошибка: ' + ERROR_MESSAGE();
END CATCH;

### Результат
Студент 1 удалён вместе с оценками. PROGRESS и STUDENT пусты.

### Анализ
Порядок удаления важен — сначала дочерняя таблица PROGRESS, потом родительская STUDENT. Иначе FK не даст удалить.

### Вывод
Транзакция гарантирует атомарность — либо удалится всё, либо ничего.

## Задача 14. Процедура с OUTPUT-параметром

### Что требовалось
Создать процедуру GetStudentInfo(student_id, OUT avg_grade, OUT total_grades), возвращающую через выходные параметры средний балл и количество оценок.

### Что сделано
Процедура принимает три параметра: @student_id, @avg_grade OUTPUT, @total_grades OUTPUT. Считает AVG и COUNT, присваивает их выходным параметрам.

CREATE OR ALTER PROCEDURE dbo.GetStudentInfo
    @student_id   INT,
    @avg_grade    DECIMAL(4,2) OUTPUT,
    @total_grades INT          OUTPUT
AS
BEGIN
    SELECT
        @avg_grade    = ISNULL(AVG(CAST(NOTE AS DECIMAL(4,2))), 0),
        @total_grades = COUNT(*)
    FROM PROGRESS WHERE IDSTUDENT = @student_id;
END;

### Проверка

DECLARE @avg DECIMAL(4,2), @cnt INT;
EXEC dbo.GetStudentInfo @student_id = 1, @avg_grade = @avg OUTPUT, @total_grades = @cnt OUTPUT;
PRINT 'Средний балл = ' + CAST(@avg AS VARCHAR(10)) + ', оценок = ' + CAST(@cnt AS VARCHAR(10));

### Результат
Средний балл = 9.50, оценок = 2.

### Анализ
OUTPUT позволяет вернуть несколько значений из процедуры за один вызов. Оба параметра объявляются с OUTPUT и в процедуре, и при вызове.

### Вывод
Удобно для получения сводной информации в одном вызове.

## Задача 15. Стипендия за семестр (курсор)

### Что требовалось
Создать процедуру AssignScholarships(), которая перебирает всех студентов и начисляет стипендию согласно среднему баллу, записывая результат в таблицу scholarships(student_id, amount, assigned_date).

### Что сделано
Создана таблица scholarships. Курсор перебирает студентов. Для каждого считается средний балл, определяется размер стипендии, INSERT в scholarships.

IF OBJECT_ID('dbo.scholarships', 'U') IS NULL
CREATE TABLE dbo.scholarships (
    student_id    INT,
    amount        INT,
    assigned_date DATE
);

CREATE OR ALTER PROCEDURE dbo.AssignScholarships
AS
BEGIN
    SET NOCOUNT ON;
    DELETE FROM dbo.scholarships;

    DECLARE @id INT, @avg DECIMAL(4,2), @amount INT;
    DECLARE cur CURSOR FOR SELECT IDSTUDENT FROM STUDENT;

    OPEN cur;
    FETCH NEXT FROM cur INTO @id;
    WHILE @@FETCH_STATUS = 0
    BEGIN
        SELECT @avg = ISNULL(AVG(CAST(NOTE AS DECIMAL(4,2))), 0)
        FROM PROGRESS WHERE IDSTUDENT = @id;

        IF @avg < 4        SET @amount = 0;
        ELSE IF @avg < 4.5 SET @amount = 2000;
        ELSE               SET @amount = 3000;

        INSERT INTO dbo.scholarships (student_id, amount, assigned_date)
        VALUES (@id, @amount, CAST(GETDATE() AS DATE));

        FETCH NEXT FROM cur INTO @id;
    END
    CLOSE cur;
    DEALLOCATE cur;
END;

### Результат

student_id | amount | assigned_date
1 | 3000 | 2026-09-18
8 | 0 | 2026-09-18
14 | 3000 | 2026-09-18

### Анализ
Курсор перебирает по одной строке. Для больших таблиц это медленно. Альтернатива — INSERT INTO ... SELECT с подзапросом.

### Вывод
Курсор удобен для сложной логики на каждой строке. Для массовых операций лучше set-based подход.

## CROSS APPLY

### Что требовалось
Показать один CROSS APPLY.

### Что сделано

SELECT S.IDSTUDENT, S.NAME, P.[SUBJECT], P.NOTE, P.PDATE
FROM STUDENT S
CROSS APPLY (
    SELECT TOP (3) [SUBJECT], NOTE, PDATE
    FROM PROGRESS
    WHERE IDSTUDENT = S.IDSTUDENT
    ORDER BY NOTE DESC
) P
ORDER BY S.IDSTUDENT, P.NOTE DESC;

### Анализ
CROSS APPLY работает как JOIN с подзапросом, который ссылается на внешнюю строку (S.IDSTUDENT). Если у студента нет оценок — он не попадёт в результат.

### Вывод
Удобно для топ-N на группу без оконных функций.

## OUTER APPLY

### Что требовалось
Показать один OUTER APPLY.

### Что сделано

SELECT S.IDSTUDENT, S.NAME, LastNote.[SUBJECT], LastNote.NOTE, LastNote.PDATE
FROM STUDENT S
OUTER APPLY (
    SELECT TOP (1) [SUBJECT], NOTE, PDATE
    FROM PROGRESS
    WHERE IDSTUDENT = S.IDSTUDENT
    ORDER BY PDATE DESC
) LastNote
ORDER BY S.IDSTUDENT;

### Анализ
OUTER APPLY — аналог LEFT JOIN. Студенты без оценок тоже попадут в результат, поля из подзапроса будут NULL. У нас такой студент — IDSTUDENT = 8.

### Вывод
OUTER APPLY нужен, когда важно сохранить все строки, даже без совпадений.

## 5 классических методов

### 1. INNER JOIN с агрегатом

SELECT S.IDSTUDENT, S.NAME, G.Cnt, G.AvgNote, G.MaxNote
FROM STUDENT S
JOIN (
    SELECT IDSTUDENT, COUNT(*) AS Cnt,
           AVG(CAST(NOTE AS DECIMAL(4,2))) AS AvgNote,
           MAX(NOTE) AS MaxNote
    FROM PROGRESS GROUP BY IDSTUDENT
) G ON G.IDSTUDENT = S.IDSTUDENT;

### 2. Коррелированный подзапрос

SELECT S.IDSTUDENT, S.NAME,
       (SELECT COUNT(*) FROM PROGRESS P WHERE P.IDSTUDENT = S.IDSTUDENT) AS Cnt,
       (SELECT AVG(CAST(NOTE AS DECIMAL(4,2))) FROM PROGRESS P WHERE P.IDSTUDENT = S.IDSTUDENT) AS AvgNote
FROM STUDENT S;

### 3. EXISTS

SELECT * FROM STUDENT S
WHERE EXISTS (SELECT 1 FROM PROGRESS P WHERE P.IDSTUDENT = S.IDSTUDENT AND P.NOTE >= 9);

### 4. CTE + JOIN

WITH StudentTotals AS (
    SELECT IDSTUDENT, COUNT(*) AS Cnt, AVG(CAST(NOTE AS DECIMAL(4,2))) AS AvgNote
    FROM PROGRESS GROUP BY IDSTUDENT
)
SELECT S.IDSTUDENT, S.NAME, T.Cnt, T.AvgNote
FROM STUDENT S JOIN StudentTotals T ON T.IDSTUDENT = S.IDSTUDENT;

### 5. GROUP BY + HAVING

SELECT IDSTUDENT, COUNT(*) AS Cnt, AVG(CAST(NOTE AS DECIMAL(4,2))) AS AvgNote
FROM PROGRESS
GROUP BY IDSTUDENT
HAVING AVG(CAST(NOTE AS DECIMAL(4,2))) > 8;

## 3 окна со всеми методами

### Окно 1. Все агрегаты + PARTITION BY

SELECT P.IDSTUDENT, P.[SUBJECT], P.NOTE,
       SUM(NOTE) OVER (PARTITION BY P.IDSTUDENT) AS StudentTotal,
       AVG(CAST(NOTE AS DECIMAL(4,2))) OVER (PARTITION BY P.IDSTUDENT) AS StudentAvg,
       COUNT(*) OVER (PARTITION BY P.IDSTUDENT) AS StudentCnt,
       MAX(NOTE) OVER (PARTITION BY P.IDSTUDENT) AS StudentMax,
       MIN(NOTE) OVER (PARTITION BY P.IDSTUDENT) AS StudentMin
FROM PROGRESS P;

### Окно 2. Ранжирование + LAG/LEAD

SELECT P.IDSTUDENT, P.[SUBJECT], P.PDATE, P.NOTE,
       ROW_NUMBER() OVER (PARTITION BY P.IDSTUDENT ORDER BY P.NOTE DESC) AS rn,
       RANK()       OVER (PARTITION BY P.IDSTUDENT ORDER BY P.NOTE DESC) AS rnk,
       DENSE_RANK() OVER (PARTITION BY P.IDSTUDENT ORDER BY P.NOTE DESC) AS drnk,
       NTILE(4)     OVER (PARTITION BY P.IDSTUDENT ORDER BY P.NOTE DESC) AS quartile,
       LAG(NOTE,  1, 0) OVER (PARTITION BY P.IDSTUDENT ORDER BY P.PDATE) AS PrevNote,
       LEAD(NOTE, 1, 0) OVER (PARTITION BY P.IDSTUDENT ORDER BY P.PDATE) AS NextNote
FROM PROGRESS P;

### Окно 3. Накопительный итог + FIRST/LAST_VALUE

SELECT P.IDSTUDENT, P.PDATE, P.NOTE,
       SUM(P.NOTE) OVER (PARTITION BY P.IDSTUDENT ORDER BY P.PDATE
                         ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW) AS RunningTotal,
       FIRST_VALUE(P.NOTE) OVER (PARTITION BY P.IDSTUDENT ORDER BY P.PDATE
                         ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING) AS FirstNote,
       LAST_VALUE(P.NOTE) OVER (PARTITION BY P.IDSTUDENT ORDER BY P.PDATE
                         ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING) AS LastNote,
       AVG(CAST(P.NOTE AS DECIMAL(4,2))) OVER (PARTITION BY P.IDSTUDENT ORDER BY P.PDATE
                         ROWS BETWEEN 2 PRECEDING AND CURRENT ROW) AS MovingAvg3
FROM PROGRESS P;

## Общий вывод

Задачи 1 и 6 — функции для среднего балла и стипендии. Задачи 3, 4, 8 — процедуры с проверками и транзакцией. Задача 14 — OUTPUT-параметры. Задача 15 — курсор и запись в таблицу. CROSS APPLY — топ-N на группу. OUTER APPLY — сохранение всех строк. 5 методов — JOIN, подзапрос, EXISTS, CTE, HAVING. 3 окна — агрегаты, ранжирование, накопительные итоги.

Ключевые принципы:
1. Функции — возврат значения, процедуры — действия.
2. CROSS APPLY — нет строк → нет вывода, OUTER APPLY — сохраняет всё.
3. Оконные функции работают поверх результата, не сворачивая строки.
4. Курсоры — для построчной логики; для массовых — set-based.
5. Транзакции — гарантия атомарности.
